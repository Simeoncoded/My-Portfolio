Machinery Schedules System

Making deadlines visible for Engineering, Production, and Procurement.

Project Overview

This system replaces disconnected Excel files used by multiple departments. It creates a single, centralized schedule where each machine’s engineering, procurement, and production deadlines are visible in one timeline.

For non-technical folks: think of it as a live “master schedule” that automatically updates and can be shared as a neat Excel Gantt chart for meetings.

What it does

  • Combines engineering and operations schedules into one view.
  • Generates digital Gantt charts for day-to-day tracking.
  • Exports clean Excel reports for managers and clients.
  • Sends reminder emails before and after missed deadlines.

Tech & Skills

ASP.NET Core MVC C# SQL Server Entity Framework Core EPPlus (Excel) DHTMLX Gantt Bootstrap

Smart Reserve

Natural language reservations for modern restaurants.

Project Overview

Smart Reserve lets customers talk to the system like they would talk to a host: “Book a table for 4 at 7pm tomorrow” — and the app handles availability, time, and confirmation automatically.

For clients: it reduces phone calls, speeds up bookings, and gives you a more modern first impression without replacing your existing reservation tools.

What it does

  • Accepts free-text messages and extracts date, time, party size, and notes.
  • Checks for availability and conflicts on the backend.
  • Sends a structured confirmation back to the guest.
  • Provides an internal dashboard for staff to review and adjust bookings.

Tech & Skills

ASP.NET Core MVC TypeScript React Query Tailwind CSS ASP.NET Core Web API OpenAI API Razor

Employee Payroll System

Demonstrating a full OOP class hierarchy for payroll calculations.

Project Overview

This payroll system is built as a clean object-oriented project. It uses a class hierarchy to model different employee types (for example: FullTime, PartTime, Contractor), each with its own pay rules.

The goal of this project is to clearly demonstrate inheritance, polymorphism, and encapsulation in a practical, real-world scenario.

What it does

  • Stores employees with their role, rate, and hours.
  • Calculates gross pay based on employee type.
  • Supports overtime or bonus logic per subclass.
  • Outputs a summary of payroll for all employees.

Java To-Do List Manager

A desktop to-do app using Java, Swing, AWT, and persistence.

Project Overview

A desktop to-do list application written in Java. The UI is built with Swing and AWT, and tasks are saved using File I/O and a database layer so that they persist between runs.

It’s structured as a small MVC-style project: the view is Swing/AWT forms, the model is the task objects, and the controller handles adding, updating, and persisting tasks.

What it does

  • Add, edit, and delete tasks from a desktop UI.
  • Mark tasks as completed or active.
  • Filter tasks by All, Active, or Completed.
  • Persist tasks using File I/O and/or a lightweight database.

Tech & Skills
